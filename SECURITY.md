# Security Policy

## Reporting a concern

Report suspected security issues privately to:

**agroaicontact@gmail.com**

Do not open a public issue containing credentials, private data, production endpoints, customer information, or exploitable technical detail.

## Public repository boundary

This repository must never contain:

- secrets or credentials;
- customer or partner confidential information;
- production infrastructure identifiers;
- private datasets;
- internal prompts or proprietary decision logic;
- production connector implementations;
- internal commercial or legal material.

An accidental disclosure is a security incident. Exposed credentials must be revoked or rotated; deleting a file alone is not sufficient.
