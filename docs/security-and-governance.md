# Security and Governance Principles

## Read-only first

New integrations should begin with the minimum access required for observation, validation, reconciliation, and reporting.

## Data minimization

Use the smallest controlled dataset necessary to validate a workflow.

## Provenance

Every output should preserve enough source context for a reviewer to understand where information originated and how it was classified.

## Human authority

Software may organize evidence and accelerate analysis. Official determinations remain with authorized customer personnel.

## Separation of information classes

Measured, reported, corrected, estimated, inferred, synthetic, and missing information should remain visibly distinct.

## Controlled disclosure

Public materials exclude production code, customer data, credentials, infrastructure identifiers, internal prompts, proprietary logic, and confidential commercial information.
