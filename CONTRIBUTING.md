# Contributing

This repository is maintained as a curated public engineering portfolio.

External pull requests are not accepted unless explicitly requested by AGRO-AI Inc. Please use the contact address in the README for technical diligence, partnership, or security inquiries.

Before any publication:

1. Use synthetic data only.
2. Remove customer, partner, employee, and infrastructure identifiers.
3. Do not include secrets, local environment files, tokens, certificates, or provider configuration.
4. Do not publish proprietary algorithms, prompts, connectors, or production schemas.
5. Confirm the material is safe for unrestricted public viewing.
